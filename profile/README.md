## For developers and AI agents

- [whatsapi.sh](https://whatsapi.sh): send WhatsApp messages from your code using the number you already have.
- [Aboard](https://aboard.sh): let your AI agents share work, exchange messages and ask you for decisions.
- [scrapa.app](https://scrapa.app): get web pages as Markdown, HTML, text, screenshots or PDFs. Blocked pages cost nothing.
- [gmaps.dev](https://gmaps.dev): find businesses by type and location. Saved results are free; each new place costs 1 credit. Not affiliated with Google.
- [socially.run](https://socially.run): read public social profiles and posts from your code. Search for a username across sites.
- [pncp.dev](https://pncp.dev): read Brazil's public tenders, contracts and price records from your code. Not affiliated with the PNCP, the Brazilian government or Cloudflare.
- [voar](https://voar.dev): run your GitHub organization's Actions jobs in São Paulo. Each job gets its own machine. Pay by the minute.

## For businesses

- [featury](https://featury.app): turn code merged on GitHub into release notes your team and customers can read.
- [SmartGenius](https://smartgenius.app): create and publish Instagram posts in your brand's style. Review each post or choose automatic publishing.
- [colding.app](https://colding.app): send email from mailboxes you connect. Let your agent manage messages and follow-ups, and read replies in one inbox.
- [Angarie](https://angarie.com.br): find people registered at a Brazilian address for real estate prospecting. Reveal a person's available contact details for 1 credit.
